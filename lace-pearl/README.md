# Lace & Pearl wedding invitation
Plain HTML/CSS/JS, no build. Edit the `CONFIG` object at the top of `app.js` (names, date, venue, program, texts in Turkish + English, gallery images, optional `music.src`).
Run: `python3 -m http.server` in this folder, open http://localhost:8000. All artwork is original CSS/SVG.
RSVP answers are logged to the console and saved in `localStorage` ("rsvp").
